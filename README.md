# Advent of Code

My solutions to [Advent of Code](https://adventofcode.com/), in Python.

## Layout

```
2025/
└── src/
    ├── 01/
    │   ├── main.py       # solution
    │   ├── input.txt     # puzzle input
    │   └── sample.txt    # example input from the puzzle
    └── 02/
        └── ...
utils/
└── pyutils.py            # shared helpers (path resolution, etc.)
```

Each day gets its own folder under `<year>/src/`, kept self-contained with its own input files.
